# 나의 건강 — 수면 자동기록 + 체중 추이 (개인용 Android 앱)

수면 자동 기록(슬립로그 기획안)과 체중 감량 궤적 대시보드를 한 앱으로 합친 개인용 APK.
서버·로그인·인터넷 권한이 없고 모든 데이터는 기기 내부 DB(Room)에만 저장된다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 오늘 | 어젯밤 취침·기상·수면시간, 7일 평균 대비 ±분, 최신 체중과 목표까지 남은 무게 |
| 수면 | 날짜별 가로 막대 타임라인. 탭하면 취침·기상 수정, 제외, 자동값 되돌리기 |
| 분석 | 7·30·90일: 평균 수면시간, 평균 취침·기상(원형 평균), 취침 규칙성, 중간점, 평일·주말 차이, 수면 부족 누적 |
| 체중 | 최신 실측, 추이 그래프, 목표 시뮬레이션(전체 평균·최근 속도·30% 감속), 주별 요약, 장기 기록, 실측 원장 |
| 설정 | 감지 기준값, 목표, 권한·절전 안내, CSV 내보내기, 전체 백업·복원 |

## 수면 감지

`UsageStatsManager`의 `KEYGUARD_HIDDEN`(잠금 해제)·`SCREEN_NON_INTERACTIVE`(화면 꺼짐) 이벤트를 읽는다.
필요한 권한은 "사용 정보 접근" 하나뿐이다.

1. 사용 구간 = 잠금 해제 ~ 다음 화면 꺼짐
2. 공백 구간 = 사용 구간 사이
3. 2분 이하 사용이고 앞뒤 공백이 각각 30분 이상이면 그 사용을 없애고 공백을 합침
4. 가장 긴 공백이 3시간 이상이면 수면 (시작 = 취침 + 보정 분, 끝 = 기상)
5. 조건 미충족이면 기록 없음 (추정값을 만들지 않음)

WorkManager가 매일 오전 11시쯤 지난 7일을 다시 계산해 저장하고, 앱을 열 때도 같은 수집을 한다.
수동으로 고치거나 제외한 날은 덮어쓰지 않고 자동 원본만 따로 보존한다.

## 코드 구조

- `core/` — Android 의존성 없는 순수 Kotlin: `SleepDetector`, `SleepStats`, `WeightModel`
- `collect/` — 사용 기록 읽기와 일 1회 수집 작업
- `data/` — Room DB, 설정, 백업·CSV
- `ui/` — Jetpack Compose 화면과 Canvas 차트

## 빌드

```
./gradlew testReleaseUnitTest   # 감지·통계·체중 계산 단위 테스트 + 화면 렌더링 테스트
./gradlew assembleRelease       # app/build/outputs/apk/release/app-release.apk
```

Android SDK(platform 35, build-tools 35)와 JDK 17 이상이 필요하다.

### 저장소에 올리지 않는 것

- `app/src/main/assets/seed.json` — 첫 실행 때 한 번 가져오는 개인 측정 데이터. 형식은 `seed.example.json` 참고.
  없으면 빈 상태로 시작한다. 앱의 "전체 백업" 파일과 같은 형식이다.
- `signing/personal.jks` — APK 서명 키. 없으면 디버그 키로 서명된다.
  서명 키가 바뀌면 기존 앱 위에 덮어 설치할 수 없으므로, 그럴 때는 앱에서 "전체 백업"을 만든 뒤
  삭제·재설치하고 "백업 복원"을 한다.
