# 글자토글 (개인용)

누를 때마다 휴대폰 글자 크기를 **큰 크기 ↔ 작은 크기**로 바꾸는 앱.

- 홈 아이콘: 누르면 화면 없이 바로 토글
- 빠른 설정 타일 "글자 크기": 상단바 › 편집 › 타일 추가
- 1×1 위젯
- 설정 화면: 아이콘 길게 누르기 › "설정" (또는 타일 길게 누르기)

## 처음 설정
1. 설정 화면에서 "시스템 설정 변경 권한" 허용
2. 폰 설정 › 글자 크기와 스타일에서 슬라이더를 맨 오른쪽에 둔 뒤 → "지금 크기를 큰 크기로 저장"
3. 슬라이더를 왼쪽에서 4번째 칸에 둔 뒤 → "지금 크기를 작은 크기로 저장"

## 빌드
`fonttoggle/**` 를 바꿔 push하면 GitHub Actions가 APK를 만들어
릴리스 `fonttoggle-latest` 에 `fonttoggle.apk` 로 올린다.
