# 꼬리 시나리오 형식

점 하나(목표가)는 틀릴 수밖에 없고 꼬리를 숨긴다. 결과의 **분포**와 **양쪽 극단**을 보여준다(나심 탈레브: 두꺼운 꼬리, 비대칭, 파산 회피).

## 금지

- 헤드라인이나 결론에 단일 목표가·적정가·"상승여력 n%"를 두지 않는다.
- 정규분포·±1σ로 범위를 만들지 않는다. 극단값은 과거 실제 사례에서 가져온다.
- 꼬리 확률을 0%로 두지 않는다. 물리적으로 불가능한 경우만 예외.
- 확률 없는 시나리오 나열(낙관/중립/비관만)을 쓰지 않는다.

## 필수 구성 (이 순서)

1. **기준점**: 기준일, 현재가, 출처.
2. **시나리오 표** (4~6개, 양쪽 꼬리 반드시 포함):

   | 시나리오 | 촉발 조건 | 가격(범위) | 현재 대비 | 확률 | 근거(유사 사례·기저율) | 먼저 보일 신호 | 시한 |
   |---|---|---|---|---|---|---|---|
   | 좌측 꼬리(파국) | … | … | −…% | ≥2~5% | … | … | … |
   | … | | | | | | | |
   | 우측 꼬리(대박) | … | … | +…% | ≥2~5% | … | … | … |

   - 확률 합 = 100%. 확률은 이야기보다 기저율·과거 유사 사례에서 출발하고, 어떻게 정했는지 한 줄로 적는다.
   - 극단값은 유사 사례의 실제 최고·최저(갭 하락, 거래정지, 감자, 공개매수가 등)로 잡는다.
3. **비대칭**: 좌측 꼬리 손실폭 ÷ 우측 꼬리 이익폭, 꼬리 확률 비교. 한 줄 판정(볼록 / 오목).
4. **파산 점검**: 좌측 꼬리가 오면 영구 손실이나 강제 청산이 나는가. 나면 그 꼬리를 견디는 비중 한도를 먼저 적는다(바벨: 안전자산 + 작은 볼록 베팅).
5. **신호 → 확률 갱신 규칙**: "X가 나오면 시나리오 A 확률을 …%로" 형태 3개 이상. 손절·종결 신호는 발표 전에 볼 수 있는 것으로.
6. **확률가중 기대값**은 참고용으로 맨 끝에만. 사용자가 목표가를 꼭 원하면 이 값을 "분포에서 계산한 값"으로 표시해 준다.
7. 출처 목록과 "참고 자료이며 투자 조언이 아니다" 문구.

## 시각화

차트는 목표가 선 대신 가격 구간별 확률 막대, 또는 시나리오별 범위를 가로 막대로 그린다. 꼬리 구간은 색으로 구분한다.

## 끝내기 전 점검

- [ ] 단일 목표가가 결론에 없다
- [ ] 양쪽 꼬리가 있고 확률이 0이 아니다
- [ ] 확률 합 100%, 근거 한 줄씩
- [ ] 극단값이 실제 사례에서 왔다
- [ ] 파산 점검과 갱신 규칙이 있다
- [ ] 결과를 `wiki/invest.md`에 기록했다 (이 저장소일 때)
